# 资产入场检查单（PR 用）

> **用途**：任何 PR 只要 **新增或修改** 了美术、音频、字体、模型、UI 素材或数值数据，作者与审核者都必须逐条过一遍本单。  
> **状态**：M0 版本，随资产管线成熟修订。  
> **上位文档**：[`docs/legal/NOTICE.md`](./NOTICE.md)（对外声明与登记表）、[`docs/art-pipeline.md`](../art-pipeline.md)（制作规范）、[`docs/REMAKE-PLAN.md`](../REMAKE-PLAN.md) §五（版权红线）。

**判定规则：任何一项答「否 / 不确定」，PR 不合入。** 合规决策的默认值是 **拒绝**。

---

## A. 来源与许可（每个新增文件都要能回答）

- [ ] **A1 作者明确**：能写出作者姓名/账号与联系方式（本项目成员、委托方、或第三方素材作者）。
- [ ] **A2 许可明确**：能写出许可证全名（MIT / CC0 / CC-BY-4.0 / SIL OFL-1.1 / 商用授权合同号…）并给出许可文本链接。
- [ ] **A3 来源可溯**：有原始来源 URL、委托合同编号，或「本项目内部原创，作者 X，日期 Y」的说明。
- [ ] **A4 可再分发**：该许可允许随本项目（MIT、非商业分发）一同分发与修改；署名要求已在 NOTICE 中满足。
- [ ] **A5 已登记**：已在 [`docs/legal/NOTICE.md`](./NOTICE.md) §4 资产登记表补充对应行。

## B. 官方资产红线（最重要）

- [ ] **B1** 该资产 **不是** 从任何官方游戏、动画、模型套件、官方网站、官方周边扫描或提取而来。
- [ ] **B2** 该资产 **不是** 对官方资产的再加工（重拓扑 / 减面 / 换材质 / 改比例 / 改色 / 裁切 / 滤镜）。
- [ ] **B3** 该资产 **不是** 以官方资产为输入的生成结果（含图生图、三维重建、动作重定向自官方动画）。
- [ ] **B4** 该资产 **没有** 逐帧描摹官方图像、把官方截图用作贴图、UI 底图或参考层残留。
- [ ] **B5** 造型/配色 **可区分**：不构成对某台具体官方机体可识别专有特征组合的复制（详见 [`art-pipeline.md`](../art-pipeline.md) §0）。
- [ ] **B6** 音频 **没有** 使用官方 BGM/SE/语音，旋律与原作曲目 **无实质性相似**。
- [ ] **B7** 文本 **没有** 复制官方剧本、台词或官方译文成段内容。
- [ ] **B8** 字体 **不是** 官方专有字体；所用字体的授权允许嵌入与再分发。

## C. 数据与数值

- [ ] **C1** 新增/修改的数值是 **本项目自建的相对强度设计**（`power_budget` 体系），不是官方数值表的转录、导出或反推。
- [ ] **C2** 机制标签（换装 / 变形 / 装甲等）来自 **公开设定与公开攻略社区的机制描述**，不是提取自游戏文件。
- [ ] **C3** 未引入任何来自 ROM / depot / 安装包的文件、配置表或二进制资源。
- [ ] **C4** 未在仓库中加入针对原作专有格式的拆包、解密、反编译工具或教程（含脚本片段与外链教程）。

## D. 对外表述

- [ ] **D1** 新增文案 **没有** 使用「官方」「正版」「授权」「重制版」等暗示授权的措辞。
- [ ] **D2** 若新增了面向外部的页面/说明，包含或链接了 **非官方声明**（见 [`NOTICE.md`](./NOTICE.md) §1）。
- [ ] **D3** 未把官方截图、官方 LOGO、官方商标图形用作项目图标、封面或宣传图。

## E. 工程与流程

- [ ] **E1** 资产路径与命名符合 [`art-pipeline.md`](../art-pipeline.md) §3。
- [ ] **E2** 网格/贴图预算符合 §4–§5（超预算需在 PR 说明理由）。
- [ ] **E3** 数据条目的 `asset_binding` 已同步；仍是占位则 `placeholder: true`。
- [ ] **E4** `python3 tools/data_validator/validate.py --strict` 通过；必要时已 `make validate-data` 刷新构建产物。
- [ ] **E5** 未提交任何密钥、证书、平台 SDK、devkit 文件或 NDA 覆盖的内容。
- [ ] **E6** 未提交对照录像 / 母带 / 官方安装目录内容（`reference/`、`*.mp4` 等已在 `.gitignore`，勿绕过）。

## 登记模板（复制到 NOTICE.md §4）

```markdown
| `<资产 ID>` | 3D/2D/音频/字体 | <作者> | <许可> | <来源 URL 或合同号> | <备注：是否占位、依赖数据条目> |
```

## 审核者备注

- 对「不确定」项，优先要求作者补证据而不是自行推断。
- 涉及外部素材时，把许可文本快照留在 PR 讨论里（链接可能失效）。
- 每个里程碑发布前做 **全量资产审计**，与 NOTICE 登记表逐行对账（REMAKE-PLAN §5.3）。
- 收到权利人通知时，按 NOTICE §6 在 **48 小时内** 停止分发并移除争议内容。
